Signals a Clinic Can Fix in One Week

AI Crawler Access and Technical Foundation together make up 45% of the score and can be corrected in days because they are server-level.

  • Confirm the server returns HTTP 200 with readable text.
  • Add or correct robots.txt so GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended, and CCBot are not blocked.
  • Place an llms.txt file in the root.
  • Add a canonical URL, language declaration on the html tag, and mobile viewport meta.
  • Keep response time under 1.5s and total HTML size under 1.5 MB.
  • Ensure all images carry alt text so image alt coverage reaches at least 80%.
  • Verify the page contains content in raw HTML rather than loading it with JavaScript.

These checks appear in the AI Crawler Access and Technical Foundation groups. Signals That Take Months to Build

Structured Data (GEO) and Answer-Readiness (AEO) require sustained editorial work and cannot be faked with a plugin in one sprint.

For Structured Data (GEO):

  • Add valid JSON-LD for Organization or LocalBusiness plus Service markup.

  • Include sameAs links to verified profiles.

  • Supply Open Graph tags with title, description, and image.

  • Add FAQ or Article schema that actually matches the visible page text.

For Answer-Readiness (AEO):

  • Write one exact H1 under 70 characters.

  • Structure the page with H2 and H3 that read as questions.

  • Produce content depth of at least 300 words that contains lists or tables of extractable facts.

  • Add dates that act as freshness signals.

  • Use semantic HTML5 landmarks so the model can parse sections without hallucinating structure.
